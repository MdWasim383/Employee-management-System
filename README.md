# Employee Management System

A **Spring Boot-based Employee Management System** developed to manage employee records using REST APIs and CRUD operations.

## 🚀 Features

* Add new employees
* View employee details
* Update employee information
* Delete employees
* RESTful API architecture
* Maven-based project
* Docker support

## 🛠️ Technologies

* Java 17
* Spring Boot 3.+
* Spring Web
* Maven
* Docker
* REST API

## 📂 Project Structure

```text
Employee-management-System/
├── src/
├── .mvn/
├── Dockerfile
├── pom.xml
├── mvnw
└── mvnw.cmd
```

## ▶️ Run the Project

Using Maven:

```bash
mvn spring-boot:run
```

Using Maven Wrapper:

```bash
mvnw.cmd spring-boot:run
```

## 🐳 Docker

Build the image:

```bash
docker build -t employee-management-system .
```

Run the container:

```bash
docker run -p 8080:8080 employee-management-system
```

## 🎯 Purpose

This project is created as a **learning project** to practice Java, Spring Boot, REST APIs, CRUD operations, Maven, and Docker.
